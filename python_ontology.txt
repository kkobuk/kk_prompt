OWl 파일은 XML 기반이기 때문에, 내용을 그대로 붙여넣으면 Protégé에서 열 수 있습니다.

동물 온톨로지 예제 (OWL)
<?xml version="1.0"?>
<rdf:RDF xmlns="http://example.com/myontology#"
     xml:base="http://example.com/myontology"
     xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#"
     xmlns:owl="http://www.w3.org/2002/07/owl#"
     xmlns:xsd="http://www.w3.org/2001/XMLSchema#"
     xmlns:rdfs="http://www.w3.org/2000/01/rdf-schema#">
     
    <owl:Ontology rdf:about="http://example.com/myontology"/>

    <!-- Classes -->
    <owl:Class rdf:about="#Animal"/>
    <owl:Class rdf:about="#Dog">
        <rdfs:subClassOf rdf:resource="#Animal"/>
    </owl:Class>
    <owl:Class rdf:about="#Cat">
        <rdfs:subClassOf rdf:resource="#Animal"/>
    </owl:Class>

    <!-- Data Properties -->
    <owl:DatatypeProperty rdf:about="#hasColor"/>
    <owl:DatatypeProperty rdf:about="#hasOwner"/>

    <!-- Object Properties -->
    <owl:ObjectProperty rdf:about="#isFriendOf"/>

    <!-- Individuals -->
    <owl:NamedIndividual rdf:about="#Baekgu">
        <rdf:type rdf:resource="#Dog"/>
        <hasColor rdf:datatype="http://www.w3.org/2001/XMLSchema#string">White</hasColor>
        <hasOwner rdf:datatype="http://www.w3.org/2001/XMLSchema#string">Kim</hasOwner>
        <isFriendOf rdf:resource="#Happy"/>
    </owl:NamedIndividual>

    <owl:NamedIndividual rdf:about="#Happy">
        <rdf:type rdf:resource="#Dog"/>
        <hasColor rdf:datatype="http://www.w3.org/2001/XMLSchema#string">Brown</hasColor>
        <hasOwner rdf:datatype="http://www.w3.org/2001/XMLSchema#string">Lee</hasOwner>
    </owl:NamedIndividual>

    <owl:NamedIndividual rdf:about="#Nari">
        <rdf:type rdf:resource="#Cat"/>
        <hasColor rdf:datatype="http://www.w3.org/2001/XMLSchema#string">Black</hasColor>
        <hasOwner rdf:datatype="http://www.w3.org/2001/XMLSchema#string">Park</hasOwner>
        <isFriendOf rdf:resource="#Mimi"/>
    </owl:NamedIndividual>

    <owl:NamedIndividual rdf:about="#Mimi">
        <rdf:type rdf:resource="#Cat"/>
        <hasColor rdf:datatype="http://www.w3.org/2001/XMLSchema#string">Gray</hasColor>
        <hasOwner rdf:datatype="http://www.w3.org/2001/XMLSchema#string">Choi</hasOwner>
    </owl:NamedIndividual>

</rdf:RDF>

owl 파일 만든걸 이용해서 ai에 적용하는방법

좋아요! 이미 만든 **OWL 파일(예: animal_ontology.owl)**을 AI에 적용하는 방법을 쉽게 설명드릴게요. 여기서 말하는 AI는 온톨로지를 이해하고 질의·추론·추천에 활용할 수 있는 시스템을 의미합니다.

OWL 파일을 AI에 적용하는 단계
1️⃣ 준비: OWL 파일 확인
OWL 파일은 XML 기반이므로 기계가 읽을 수 있는 지식 구조입니다.
Protégé에서 만든 animal_ontology.owl은 이미 클래스, 개체, 속성, 관계가 정의되어 있습니다.
2️⃣ AI에서 OWL 읽기

AI가 OWL을 활용하려면 RDF/OWL 파서 라이브러리가 필요합니다.
대표적인 예시:

Python
rdflib 라이브러리 사용
from rdflib import Graph

# OWL 파일 로드
g = Graph()
g.parse("animal_ontology.owl")

# 전체 트리플 확인
for s, p, o in g:
    print(s, p, o)
결과: OWL에 정의된 모든 클래스, 개체, 관계가 (주어, 술어, 목적어) 형태로 출력됩니다.
3️⃣ AI에 적용 가능한 활용 방법
3-1. 질의(Query)
SPARQL 같은 쿼리 언어를 사용해서 AI가 질문에 답할 수 있습니다.
from rdflib.plugins.sparql import prepareQuery

q = prepareQuery("""
    SELECT ?dog
    WHERE {
        ?dog rdf:type :Dog .
    }
""", initNs={"": "http://example.com/myontology#"})

for row in g.query(q):
    print(row.dog)
결과: Dog 클래스에 속하는 개체 이름 출력 (Baekgu, Happy)
3-2. 추론(Inference)
온톨로지의 관계 규칙을 AI가 이해하도록 추가
예: isFriendOf 관계를 따라 친구 추천
Python에서 owlready2 라이브러리 사용 가능
from owlready2 import *

onto = get_ontology("animal_ontology.owl").load()

# Baekgu 친구 확인
baekgu = onto.Baekgu
print(baekgu.isFriendOf)  # Happy
AI 모델과 결합하면:
“Baekgu의 친구는 누구인가?” → AI가 자동으로 추론
3-3. 자연어 질의와 결합
온톨로지를 AI 언어 모델과 연결
예: GPT 계열 모델 + OWL 지식
사용자가 “Baekgu 친구 알려줘” 입력
Python 코드가 OWL 파서로 추출
결과를 AI 모델에 전달 → 자연어 답변 생성
4️⃣ AI 통합 워크플로
OWL 파일 → Python 라이브러리(owlready2/rdflib) → 데이터 구조 변환 → AI 모델 질의/추론
선택적: 그래프 DB로 변환 후 AI와 연결
Neo4j + OWL → AI가 그래프 기반 질의 가능

Python + py2neo 사용 예제
from py2neo import Graph, Node, Relationship
from rdflib import Graph as RDFGraph

# Neo4j 연결
graph = Graph("bolt://localhost:7687", auth=("neo4j", "password"))

# OWL 파일 읽기
g = RDFGraph()
g.parse("animal_ontology.owl")

# RDF 트리플을 Neo4j 노드/관계로 변환
for s, p, o in g:
    s_node = Node("Entity", name=str(s))
    o_node = Node("Entity", name=str(o))
    graph.merge(s_node, "Entity", "name")
    graph.merge(o_node, "Entity", "name")
    rel = Relationship(s_node, str(p), o_node)
    graph.merge(rel)

Python 실습 코드: OWL → Neo4j → AI 질의
# 1️⃣ 라이브러리 설치 (한 번만)
# pip install rdflib py2neo owlready2

from rdflib import Graph as RDFGraph
from py2neo import Graph, Node, Relationship

# ----------------------
# 2️⃣ Neo4j 연결 설정
# ----------------------
neo4j_url = "bolt://localhost:7687"
neo4j_user = "neo4j"
neo4j_password = "password"  # 실제 비밀번호로 변경

graph = Graph(neo4j_url, auth=(neo4j_user, neo4j_password))

# ----------------------
# 3️⃣ OWL 파일 읽기
# ----------------------
owl_file = "animal_ontology.owl"  # Protégé에서 만든 OWL 파일
g = RDFGraph()
g.parse(owl_file)

# ----------------------
# 4️⃣ RDF 트리플 → Neo4j 노드/관계 변환
# ----------------------
for s, p, o in g:
    # 노드 생성 (클래스/개체)
    s_node = Node("Entity", name=str(s))
    o_node = Node("Entity", name=str(o))
    graph.merge(s_node, "Entity", "name")
    graph.merge(o_node, "Entity", "name")
    
    # 관계 생성
    rel = Relationship(s_node, str(p), o_node)
    graph.merge(rel)

print("OWL 파일이 Neo4j 그래프에 성공적으로 로드되었습니다!")

# ----------------------
# 5️⃣ AI 질의 예제: Baekgu 친구 확인
# ----------------------
query = """
MATCH (a:Entity {name:'http://example.com/myontology#Baekgu'})-[r]->(b:Entity)
WHERE type(r) CONTAINS "isFriendOf"
RETURN b.name
"""
result = graph.run(query).data()
friends = [r['b.name'] for r in result]

print("Baekgu의 친구:", friends)

# ----------------------
# 6️⃣ AI 통합 예시 (자연어 답변)
# ----------------------
if friends:
    answer = f"Baekgu의 친구는 {', '.join(friends)}입니다."
else:
    answer = "Baekgu의 친구가 없습니다."

print("AI 응답:", answer)
설명
rdflib: OWL 파일 읽기
py2neo: Neo4j 그래프 DB에 OWL 구조를 저장
Graph.merge: 노드와 관계 중복 없이 저장
Cypher 질의: 특정 개체의 관계 추출
자연어 응답 생성: AI 모델이 사용자 질문에 답할 수 있도록 연결

이 코드는 OWL에서 Neo4j로 로드된 데이터를 조회하고, AI가 간단히 요약하도록 구성되어 있습니다.

ai_query_example.py (최신 버전)
import os
from neo4j import GraphDatabase
from openai import OpenAI

# -----------------------------
# 1️⃣ Neo4j 접속 정보
# -----------------------------
NEO4J_URI = "neo4j://localhost:7687"
NEO4J_USER = "neo4j"
NEO4J_PASSWORD = "password"  # 실제 비밀번호로 변경

driver = GraphDatabase.driver(NEO4J_URI, auth=(NEO4J_USER, NEO4J_PASSWORD))

def query_neo4j(cypher_query):
    """Neo4j 쿼리 실행"""
    with driver.session() as session:
        result = session.run(cypher_query)
        return [record.data() for record in result]

# -----------------------------
# 2️⃣ OpenAI API 설정
# -----------------------------
# 환경 변수로 설정 추천: setx OPENAI_API_KEY "your_api_key"
OPENAI_API_KEY = os.getenv("OPENAI_API_KEY")
if not OPENAI_API_KEY:
    raise ValueError("환경 변수 OPENAI_API_KEY 를 설정하세요.")

client = OpenAI(api_key=OPENAI_API_KEY)

# -----------------------------
# 3️⃣ AI 요약 함수
# -----------------------------
def ask_ai_about_animal(animal_name):
    # Neo4j에서 데이터 조회
    cypher_query = f"""
    MATCH (a:Entity)-[r]->(b:Entity)
    WHERE a.uri CONTAINS '{animal_name}'
    RETURN a.uri AS subject, type(r) AS relation, b.uri AS object
    LIMIT 10
    """
    data = query_neo4j(cypher_query)
    if not data:
        return f"No information found in Neo4j for {animal_name}."

    # AI 요약용 프롬프트 생성
    prompt = f"Here are some facts about {animal_name} from the ontology:\n{data}\nSummarize in simple language."

    # ChatCompletion 호출
    response = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=[
            {"role": "system", "content": "You are a helpful assistant."},
            {"role": "user", "content": prompt}
        ],
    )

    return response.choices[0].message.content.strip()

# -----------------------------
# 4️⃣ 실행 예시
# -----------------------------
if __name__ == "__main__":
    animal_name = "Lion"
    summary = ask_ai_about_animal(animal_name)
    print(f"AI Summary about {animal_name}:\n{summary}")

Neo4j 연동: OWL에서 로드된 데이터를 Cypher 쿼리로 조회.
OpenAI Chat API 사용: 최신 SDK 구조(client.chat.completions.create) 반영.
환경 변수 사용 권장: API Key를 코드에 직접 쓰지 않고, OPENAI_API_KEY 환경 변수로 관리.
예외 처리: Neo4j에서 데이터가 없을 경우 메시지 반환.
